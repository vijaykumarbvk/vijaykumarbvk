### 🏗️ Featured Projects

**GitHub Actions OIDC Pipeline for Terraform Deployments**
Migrated deployment workflows from static AWS credentials to OIDC-based authentication, configuring IAM trust policies and a GitHub OIDC identity provider to enable secure, keyless Terraform deployments — with plan/apply stages and approval gates for controlled, auditable changes.

**Cloud Infrastructure-as-Code Framework with Terraform (Multi-Cloud)**
Architected a multi-cloud IaC framework standardizing networking, security, and deployment patterns across AWS, Azure, and GCP. Built reusable, versioned Terraform modules that cut environment provisioning time by 70%, with remote state locking (S3 + DynamoDB) and policy-as-code checks (tfsec/Checkov).

**Centralized Application Logging with CloudWatch & Cost-Optimized S3 Archival**
Designed a centralized logging architecture using CloudWatch Log Groups with automated S3 archival, cutting log storage costs by 45%. Built a serverless log archival pipeline (Lambda + S3 lifecycle policies) and CloudWatch Logs Insights dashboards for self-serve log analysis.
